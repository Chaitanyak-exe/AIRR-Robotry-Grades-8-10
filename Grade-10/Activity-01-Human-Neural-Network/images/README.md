# Images

This folder should contain real photographs taken while performing the Human Neural Network demonstration. Do not add fake images.

Recommended filenames and descriptions:

- `network-overview.jpg` — a clear photo showing the full classroom arrangement.
- `input-layer.jpg` — photo of the input students with their labels.
- `hidden-layer-1.jpg` — photo showing Hidden Layer 1.
- `hidden-layer-2.jpg` — photo showing Hidden Layer 2.
- `connections.jpg` — close-up of strings/arrows and one labelled connection (Weight).
- `output-layer.jpg` — photo showing the output students and labels.
- `final-activity.jpg` — a final photo after the activity is complete.

Keep photos well-lit and taken from above when possible so labels and connections are readable.
