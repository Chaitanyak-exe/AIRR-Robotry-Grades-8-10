# Components Required

## Hardware Components

| No. | Component     |    Quantity | Purpose                                                          |
| --: | ------------- | ----------: | ---------------------------------------------------------------- |
|   1 | Arduino Uno   |           1 | Main microcontroller used to control the LED                     |
|   2 | LED           |           1 | Produces light when current flows through it                     |
|   3 | 220Ω Resistor |           1 | Limits current flowing through the LED                           |
|   4 | Breadboard    |           1 | Used to build the circuit without soldering                      |
|   5 | Jumper Wires  | As required | Used to make electrical connections                              |
|   6 | USB Cable     |           1 | Used to connect the Arduino to the laptop and upload the program |
|   7 | Laptop        |           1 | Used to write, compile and upload the Arduino program            |

---

## Component Details

### 1. Arduino Uno

The Arduino Uno is the main controller used in this activity.

It runs the program and controls the LED using a digital output pin.

---

### 2. LED

LED stands for **Light Emitting Diode**.

It is the output component used in this activity. It produces light when current flows through it in the correct direction.

The two terminals of a standard LED are:

- Anode (+)
- Cathode (-)

---

### 3. 220Ω Resistor

The 220Ω resistor is connected in series with the LED.

Its main purpose is to limit the current flowing through the LED and help protect the LED from excessive current.

---

### 4. Breadboard

A breadboard is used to build the circuit without soldering.

It allows the components and jumper wires to be connected and removed easily.

---

### 5. Jumper Wires

Jumper wires are used to connect the Arduino pins to the LED circuit on the breadboard.

---

### 6. USB Cable

The USB cable connects the Arduino Uno to the laptop.

It is used to:

- Upload the program to the Arduino.
- Provide power to the Arduino during the activity.

---

### 7. Laptop

The laptop is used to:

- Write the Arduino program.
- Compile the program.
- Upload the program to the Arduino.
- Observe and troubleshoot the activity.
