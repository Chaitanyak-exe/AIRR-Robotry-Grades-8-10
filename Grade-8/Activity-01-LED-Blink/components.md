# Components Required

## Hardware

| No. | Component     |    Quantity | Purpose                                                      |
| --: | ------------- | ----------: | ------------------------------------------------------------ |
|   1 | Arduino Uno   |           1 | Main microcontroller                                         |
|   2 | LED           |           1 | Produces light when current flows through it                 |
|   3 | 220Ω Resistor |           1 | Limits current through the LED                               |
|   4 | Breadboard    |           1 | Used to build the circuit without soldering                  |
|   5 | Jumper Wires  | As required | Used to make electrical connections                          |
|   6 | USB Cable     |           1 | Used to connect Arduino to the laptop and upload the program |
|   7 | Laptop        |           1 | Used for programming the Arduino                             |

---

## Component Details

### Arduino Uno

The Arduino Uno is the main controller used in this activity. It runs the program and controls the LED through a digital output pin.

### LED

The LED is the output device. It produces light when the Arduino supplies the required voltage and current.

### 220Ω Resistor

The resistor limits the current flowing through the LED and helps protect the LED from excessive current.

### Breadboard

The breadboard allows the components to be connected without soldering.

### Jumper Wires

Jumper wires are used to connect the Arduino, LED, resistor and ground.

### USB Cable

The USB cable provides a connection between the laptop and Arduino. It is used to upload the program and can also provide power to the Arduino during the activity.

### Laptop

The laptop is used to write, compile and upload the Arduino program using Arduino IDE.
