```markdown
# Components Required

## Hardware Components

| No. | Component     |    Quantity | Purpose                                     |
| --: | ------------- | ----------: | ------------------------------------------- |
|   1 | Arduino Uno   |           1 | Reads the push button and controls the LED  |
|   2 | Push Button   |           1 | Provides digital input to the Arduino       |
|   3 | LED           |           1 | Indicates the button state                  |
|   4 | 220Ω Resistor |           1 | Limits current through the LED              |
|   5 | Breadboard    |           1 | Used to build the circuit without soldering |
|   6 | Jumper Wires  | As required | Used to make electrical connections         |
|   7 | USB Cable     |           1 | Connects Arduino to the laptop              |
|   8 | Laptop        |           1 | Used to program and test the Arduino        |

## Component Details

### Arduino Uno

The Arduino Uno is the main controller used in this activity.

It reads the push button through digital pin D2 and controls the LED through digital pin D13.

### Push Button

The push button is used as the digital input device.

Pressing the button allows the Arduino to detect a button press.

### LED

The LED is used as the output indicator.

It turns ON when the Arduino detects that the push button has been pressed.

### 220Ω Resistor

The resistor is connected in series with the LED.

It limits the current flowing through the LED and helps protect it.

### Breadboard

The breadboard is used to build the circuit without soldering.

### Jumper Wires

Jumper wires connect the Arduino, push button, LED and GND.

### USB Cable

The USB cable connects the Arduino Uno to the laptop.

It is used to upload the program and provide power to the Arduino.

### Laptop

The laptop is used to:

- Write the Arduino program.
- Upload the program.
- Open the Serial Monitor.
- Observe and troubleshoot the activity.
```
