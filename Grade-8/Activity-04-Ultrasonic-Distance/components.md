## Component Details

### Arduino Uno

The Arduino Uno is the main controller used in this activity.

It sends the trigger signal to the HC-SR04, measures the returning echo and calculates the distance.

### HC-SR04 Ultrasonic Distance Sensor

The HC-SR04 is an ultrasonic distance sensor.

It uses ultrasonic sound waves to detect the distance of an object.

The sensor has four pins:

- VCC
- GND
- TRIG
- ECHO

The Grade 8 book describes the HC-SR04 as a common hobbyist ultrasonic sensor with a typical measuring range of 2 cm to 400 cm. :contentReference[oaicite:6]{index=6}

### Breadboard

The breadboard is used to build the circuit without soldering.

### Jumper Wires

Jumper wires are used to connect the HC-SR04 to the Arduino.

### USB Cable

The USB cable connects the Arduino Uno to the laptop.

It is used to upload the program and provide power to the Arduino.

### Laptop

The laptop is used to:

- Write the Arduino program.
- Upload the program.
- Open the Serial Monitor.
- Observe distance readings.
