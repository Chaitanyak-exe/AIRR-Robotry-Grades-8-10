# Components Required

## Hardware Components

| No. | Component                  |    Quantity | Purpose                                         |
| --: | -------------------------- | ----------: | ----------------------------------------------- |
|   1 | Arduino Uno                |           1 | Reads the IR sensor and controls the LED        |
|   2 | IR Object Detection Sensor |           1 | Detects nearby objects                          |
|   3 | LED                        |           1 | Indicates object detection                      |
|   4 | 220Ω Resistor              |           1 | Limits current through the LED                  |
|   5 | Breadboard                 |           1 | Used to build the circuit                       |
|   6 | Jumper Wires               | As required | Used to make connections                        |

---

## Component Details

### Arduino Uno

Arduino Uno is the controller used in this activity.

It reads the digital output of the IR sensor and controls the LED.

### IR Object Detection Sensor

The IR sensor is used to detect nearby objects.

It uses infrared light and a receiver to detect reflected infrared light.

The output is generally a digital HIGH or LOW signal.

### LED

The LED provides a visual indication when an object is detected.

### 220Ω Resistor

The resistor limits current through the LED and helps protect it.

### Breadboard

The breadboard allows the circuit to be assembled without soldering.

### Jumper Wires

Jumper wires are used to connect the sensor and LED to the Arduino.

### USB Cable

The USB cable connects the Arduino to the laptop for programming and power.

### Laptop

The laptop is used to:

- Write the Arduino program.
- Upload the program.
- Open the Serial Monitor.
- Observe sensor readings.
