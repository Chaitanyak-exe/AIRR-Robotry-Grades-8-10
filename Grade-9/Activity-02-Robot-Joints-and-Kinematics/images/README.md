# Images

This folder is for photos taken while performing the activity. Do not add photos here unless they are actual photos from your experiment.

Please add the following image files after you perform the activity:

- `components.jpg` — Photo of the components laid out (links, fasteners, ruler, protractor).
- `model.jpg` — Photo of the built 2-link model on the paper base.
- `angle-setup.jpg` — Photo showing the protractor and the set joint angles.
- `test-result.jpg` — Photo showing the measured X and Y for one test.

Keep file names exactly as above and add them to this folder when available.
