# Components / Requirements

| No. | Component / Software | Quantity | Purpose                                 |
| --- | -------------------- | -------: | --------------------------------------- |
| 1   | Laptop               |        1 | Run Python and the code                 |
| 2   | Python 3             |        1 | Programming language (python3)          |
| 3   | scikit-learn         |        1 | Provides dataset and classifier         |
| 4   | numpy                |        1 | Numeric operations used by scikit-learn |
| 5   | Text editor / IDE    |        1 | Edit and run `code/main.py`             |

## Hardware

No additional electronic hardware is required for this activity.

## Software

- `python3` (version 3.7 or newer recommended)
- `scikit-learn` and `numpy` installed via `pip`
