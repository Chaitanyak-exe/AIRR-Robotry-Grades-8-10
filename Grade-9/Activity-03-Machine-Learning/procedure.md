# Procedure – Machine Learning Activity

1. Prepare the laptop and open a terminal.

2. Install required libraries (if not already installed):

```bash
python3 -m pip install --user scikit-learn numpy
```

3. Create the activity folder and open `code/main.py` in your editor.

4. Run the program:

```bash
python3 code/main.py
```

5. Observe the printed output: training/test sizes, accuracy, and example predictions.

6. Try the interactive option: when prompted, enter four numeric feature values separated by spaces to get a prediction.

7. Record the accuracy and example predictions on paper.

8. Repeat with different `k` values in `code/main.py` (for example `k=1` and `k=5`) and compare accuracies.

9. Take photos of your setup and output to add to the `images/` folder.

Notes:

- Save `code/main.py` in the `code/` folder inside this activity.
- Use `python3` so the commands work on Linux/Mac. On Windows replace `python3` with your Python launcher if needed.
