# Components / Requirements

## Hardware

| No. | Component | Quantity | Purpose                                   |
| --: | --------- | -------: | ----------------------------------------- |
|   1 | Laptop    |        1 | Runs Python and trains the neural network |

No Arduino, ESP32, sensors or other electronic hardware is required.

---

## Software

| No. | Software / Library | Purpose                           |
| --: | ------------------ | --------------------------------- |
|   1 | Python 3           | Runs the program                  |
|   2 | NumPy              | Stores and manages numerical data |
|   3 | scikit-learn       | Provides the neural network model |
|   4 | Terminal / VS Code | Used to run and edit the program  |

---

## Installation

Install NumPy and scikit-learn:

```bash
python3 -m pip install --user numpy scikit-learn
```

If you do not have `pip` or installation permission, ask your teacher or use a virtual environment.
