## Connections

There is no electronic circuit for this activity.

For a built-in webcam:

Built-in Webcam
↓
Laptop
↓
Python + OpenCV

For a USB webcam:

USB Webcam
↓
USB Port
↓
Laptop
↓
Python + OpenCV

No external power supply or electronic circuit is required.

# Components – Computer Vision

## Hardware Components

| No. | Component      | Quantity | Purpose                 |
| --- | -------------- | -------: | ----------------------- |
| 1   | Laptop/Desktop |        1 | Runs the Python program |
| 2   | Webcam         |        1 | Captures live video     |

### Webcam

A webcam is required to capture live video.

The built-in webcam of a laptop can be used.

An external USB webcam can also be used if required.

# Python Library

## OpenCV

OpenCV stands for:

**Open Source Computer Vision Library**

It is used in this activity to:

- Access the webcam
- Capture video frames
- Convert images to greyscale
- Display video
- Process images

Install OpenCV using:

```bash
python3 -m pip install opencv-python
```
