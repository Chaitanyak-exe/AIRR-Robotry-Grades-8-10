# Images

Do not add fake images. This folder should contain real screenshots or photos taken while performing the activity. Suggested filenames and what they should show:

- `program.jpg` — Editor or terminal showing `code/main.py` open.
- `colour-camera.jpg` — Screenshot/photo of the `Colour Camera` window showing live colour video.
- `greyscale-camera.jpg` — Screenshot/photo of the `Greyscale Camera` window showing live greyscale video.
- `mirror-mode.jpg` — Screenshot showing the mirror mode (if performed).
- `text-overlay.jpg` — Screenshot showing the text overlay (if performed).
- `rectangle.jpg` — Screenshot showing the rectangle overlay (if performed).

Keep photos clear and readable. Use PNG or JPG formats. Add them to this folder after you run the activity and take the screenshots.
