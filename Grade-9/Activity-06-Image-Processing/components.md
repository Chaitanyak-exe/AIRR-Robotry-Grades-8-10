# Components – Image Processing

| No. | Component / Software     | Quantity | Purpose                              |
| --: | ------------------------ | -------: | ------------------------------------ |
|   1 | Laptop/Desktop           |        1 | Run Python and the program           |
|   2 | Input image file         |        1 | Photo to process (place in `input/`) |
|   3 | Python 3                 |        1 | Run scripts (`python3`)              |
|   4 | OpenCV (`opencv-python`) |        1 | Image processing functions           |
|   5 | Text editor / VS Code    |        1 | Edit and view code                   |
|   6 | Terminal                 |        1 | Run install and program commands     |

## Software Requirements

- Python 3 (3.7 or newer recommended)
- `opencv-python` (OpenCV)

## Installation

Install OpenCV with:

```bash
python3 -m pip install opencv-python
```

Verify installation:

```bash
python3 -c "import cv2; print('OpenCV version:', cv2.__version__)"
```

## Connections

There are no electronic circuits or hardware connections for this activity. You only need a computer and an input image file placed in the `input/` folder.

No Arduino, ESP32, sensors, motors or other electronics are required.
