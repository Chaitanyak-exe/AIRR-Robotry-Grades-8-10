# Images

This folder is for real screenshots or photos taken while performing the activity. Do not add fake images.

Suggested files and what they should show:

- `original.jpg` — the original input photo used for the activity (or a screenshot of the file in the editor).
- `greyscale.jpg` — the greyscale result saved by the program.
- `blur_3.jpg`, `blur_9.jpg`, `blur_21.jpg` — results of Gaussian blur with different kernel sizes.
- `canny.jpg` — result of Canny edge detection.
- `threshold_simple.jpg` — simple thresholding result (threshold 127).
- `threshold_adaptive.jpg` — adaptive thresholding result.
- `threshold_otsu.jpg` — Otsu's thresholding result.

Add images after running `code/main.py` and copying or moving the output files into this folder if you want them as part of the activity documentation.
