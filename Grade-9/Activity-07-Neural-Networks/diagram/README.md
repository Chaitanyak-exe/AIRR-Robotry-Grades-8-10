# Diagram

This folder is for the neural-network diagram files. You can draw the network on paper and take photos, or create a digital drawing and save it here.

Suggested filenames:

- `network-drawing.jpg` — a clear photograph of your paper drawing or a screenshot of a digital drawing.
- `labelled-network.jpg` — the same drawing with labels highlighted.
- `connections.jpg` — a close-up showing connections and one labelled weight (for example `w1`).
- `final-result.jpg` — final cleaned-up diagram.

You may also save an editable vector or SVG file if you created the diagram digitally (for example `network.svg`).
